# Software Engineering — Project Tracker

A small, browser based project tracker for organizing software work. Create projects, add tasks, mark them complete, search project names and descriptions, and see progress at a glance.

## Run it

Open `index.html` in a modern browser. No installation or server is required. Projects are saved in that browser's local storage.

## Files

- `index.html` — page structure and project form
- `styles.css` — responsive dark interface
- `app.js` — project and task behavior, saved locally

The two sample projects are only initial demo data. You can delete them or add your own.
